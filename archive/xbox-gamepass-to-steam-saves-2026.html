Как добавить сохранения из Game Pass PC? Перенос сейвов без потери прогресса

6 июля 2026 · обновлено 22 июля 2026 7 мин Гайды

Сохранения игр из PC Game Pass иногда не находятся там, где пользователь ожидает их увидеть. В некоторых играх прогресс синхронизируется через Xbox/Microsoft, в других сохранение хранится локально, а у отдельных игр используется собственная система сохранений.

Поэтому простое копирование файла из одной папки в другую работает далеко не всегда. В этом руководстве разберём, как правильно перенести прогресс из Game Pass на ПК — с облачной синхронизацией, ручным поиском и переносом в Steam.

1. Сначала определите, откуда сохранение

Если вы играли через PC Game Pass, речь идёт о версии игры из Microsoft Store/Xbox. Это важно, потому что сохранение Game Pass может отличаться от сохранения Steam-версии той же игры.

Например, переход Game Pass → Steam может потребовать конвертацию сохранения. А Game Pass → Game Pass обычно значительно проще, особенно если игра поддерживает облачную синхронизацию.

2. Проверьте облачное сохранение

Перед ручным поиском файлов сначала запустите игру через Game Pass и убедитесь, что ваш старый прогресс действительно загружается. Если сохранение появляется после запуска игры — не нужно искать его вручную.

Xbox автоматически синхронизирует сохранения с аккаунтом Microsoft, если конкретная игра поддерживает облачные сохранения. Если игра предлагает выбрать между локальным и облачным сохранением, выбирайте вариант, где находится ваш актуальный прогресс.

3. Если сохранение нужно найти вручную

Здесь универсального пути нет. Разные игры используют разные места для сохранений:

  • Documents\My Games
  • AppData\Local
  • AppData\LocalLow
  • AppData\Roaming
  • папки самой игры;
  • защищённое хранилище Microsoft Store/Xbox.

При этом папка установки игры из Game Pass не обязательно содержит сами сохранения. Не стоит без необходимости менять файлы внутри WindowsApps — это защищённая системная директория, и неправильное изменение её содержимого может привести к проблемам с установкой игры.

4. Game Pass → Steam

Это самый сложный вариант. Даже если вы нашли сохранение Game Pass, Steam может его не распознать. Причина в том, что разные версии игры могут использовать:

  • другой формат файла;
  • другой идентификатор профиля;
  • другую структуру папок;
  • шифрование;
  • собственную систему облачных сохранений.

Поэтому сначала нужно выяснить, поддерживает ли конкретная игра перенос сохранений между Game Pass и Steam. Если поддерживает — обычно достаточно перенести сохранение в папку Steam-версии или воспользоваться конвертером. Если не поддерживает — простое копирование файла может закончиться тем, что игра начнёт новое прохождение.

5. Перед переносом обязательно сделайте резервную копию

Это самый важный пункт. Перед любыми манипуляциями скопируйте исходное сохранение в отдельную папку, например Game Save Backup. Если после переноса игра перестанет видеть прогресс, можно вернуть оригинальный файл. Никогда не удаляйте оригинальное сохранение до проверки нового.

6. Если игра не видит сохранение

Попробуйте по порядку:

  1. Запустить игру и создать новое сохранение.
  2. Закрыть игру.
  3. Найти папку, в которой появился новый сейв.
  4. Сделать резервную копию этого нового файла.
  5. Заменить его копией старого сохранения.
  6. Запустить игру.
  7. Проверить загрузку старого прогресса.

Этот способ часто помогает определить, куда именно игра записывает сохранения.

Важный момент

Не существует одной универсальной папки «сейвы Game Pass». Место хранения зависит от конкретной игры и её версии. Поэтому если вы хотите перенести сохранение определённой игры, самый надёжный способ — искать инструкцию именно по запросу: «название игры Game Pass save location» или «название игры Game Pass save transfer Steam».

Если ничего из этого не помогло

У конкретной игры может быть собственная система сохранений или ограничения на перенос между версиями. В таком случае ниже можно посмотреть подробное пошаговое объяснение процесса.
