Как добавить игру

  

    1. Заведи в репозитории папку games/имя-игры/ и положи туда index.html (GitHub → Add file → Upload files).

    2. Здесь заполни форму → Добавить игру.

    3. Скачать games.js → замени одноимённый файл в репозитории.

    4. Через минуту игра появится на сайте со своей ссылкой: адрес-сайта/games/имя-игры/.

    Индекс сайта сам вшивает превью, поиск и статистику запусков — в самой игре ничего править не нужно.
